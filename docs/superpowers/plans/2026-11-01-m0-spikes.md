# M0 Spikes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every `[spike]` in the plan docs with a measurement and pass the M0 gate: 5,000 elements @ 60 fps; Arabic server render OK or fallback chosen; extraction default, models and embedding chosen; deploy dry-run (WS + SSE behind basic auth) works.

**Architecture:** Five throwaway spikes under `spikes/<id>/`, each a small pnpm workspace package that prints PASS/FAIL against thresholds and writes a `RESULT.md` (environment, numbers, decision lines). The last task distils the results into the plan docs and revisits the scope and order of M1–M7. Tasks 1–3 need no outside input; Task 4 needs the OpenRouter key, Task 5 a VPS, Tasks 6–7 the books.

**Tech Stack:** Node 22.21.1 · pnpm 12.8.1 · `tsx` 4.23 · Vite 8.3 (S1 page only) · `rbush` 4.0.1 · `perfect-freehand` 1.2.3 · `@napi-rs/canvas` 1.1.0 · `@mathjax/src` 4.1.3 · `@fontsource/noto-naskh-arabic` and `@fontsource/ibm-plex-sans-arabic` 5.3.0 · `better-sqlite3` 13.0.3 · `ai` 7.0.159 + `@openrouter/ai-sdk-provider` 3.1.0 · `pdfjs-dist` 6.4.299 · `zod` 4.6.7 · `@nestjs/core` + `@nestjs/platform-ws` 12.3 · `next` 16.4 (versions seen on npm 2026-11-01; pin exact at install).

**Spec:** [ROADMAP.md](../../ROADMAP.md) §2 K and M0 · [testing-spikes.md](../../plans/testing-spikes.md) (spike table, risks) · [PLAN.md](../../PLAN.md) §17–§19.

## Global Constraints

- pnpm only: never npm, yarn, bun or `npx` (use `pnpm exec` / `pnpm dlx`). Root `package.json` pins `"packageManager": "pnpm@12.8.1"`; commit `pnpm-lock.yaml`; never create `package-lock.json`. Node 22 LTS.
- Targets from the spec: 5,000 visible elements at 60 fps; first ink within one frame (≤ 16 ms); a 20,000-element board opens in < 2 s; exact vector search under ~100 ms; library vector cache cap 512 MB.
- `OPENROUTER_API_KEY` lives only in `.env` (gitignored). It never appears in logs, `RESULT.md`, screenshots or commits.
- The VPS is Debian 12+ or Ubuntu 24.04 LTS on glibc, not Alpine.
- Paid calls total ≤ $3 for M0 (the user's limit, 2026-11-01). **[my call]** split: S3 ≤ $1.50, S2 ≤ $1, S4b ≤ $0.50. Every script keeps a running total and aborts at its ceiling; set the key's OpenRouter credit limit to $3.
- **[my call]** Spike code is throwaway TypeScript run with `tsx` (Vite for the S1 page): no abstractions, no lint or type gate. The thresholds below are the tests.
- Work on branch `m0-spikes`, one commit per task (the user approved this on 2026-11-01). Stage only the task's own files, never `git add -A` or `git commit -a`; the commit message ends with the `Claude-Session:` trailer the controller gives in the dispatch.
- Each spike writes `spikes/<id>/RESULT.md` with three headings: Environment, Numbers, Decisions (one `name: value` line each). Only Task 8 edits the plan docs.

## Review Focus

Each line is pinned by a test in the task named.

1. A benchmark that passes on a toy scene of rectangles. Expected: the 5,000 elements carry the real type mix (Latin and Arabic text, cached math and image bitmaps, strokes, rotated shapes) and culling stays correct at zoom 0.05 and 20 → Task 1 steps 2 and 4.
2. Arabic renders only because the dev Mac has system Arabic fonts. Expected: the bundled font is the one drawn, and it also renders on a VPS with none → Task 2 step 2, Task 5 step 3(f).
3. The cost cap never fires because streaming omits cost (the docs' own warning). Expected: a step with no cost fails the run loudly → Task 4 `streamingCost` and the running-total abort.
4. Eval pages in printed numbering while chunks use file page indices. Expected: every expected page is normalised to a 1-based file index and lies inside the book → Task 7 step 2.
5. Latency and memory measured on a Mac, shipped on a 2 GB VPS. Expected: the same script runs on the VPS and stays inside the cache cap → Task 3 step 3, Task 5 step 3(f).

### Task 1: S1 browser canvas benchmark *(no inputs needed)*

**Files:**
- Create: `package.json`, `pnpm-workspace.yaml`, `spikes/s1-canvas/package.json` (name `s1-canvas`; deps `rbush`, `perfect-freehand`; dev `vite`), `spikes/s1-canvas/web/{index.html,scene.ts,render.ts,bench.ts}`, `spikes/s1-canvas/RESULT.md`
- Modify: `.gitignore` (add `spikes/*/out/`)

**Interfaces:**
- Produces: `window.__s1: S1Result`, and RESULT.md decisions `textStrategy: direct|cached`, `renderThread: main|worker`, `spatialIndex: rbush|in-house`, `freehand: perfect-freehand|in-house`.

```ts
type Variant = 'direct' | 'cached' | 'worker';
type S1Result = {
  env: { ua: string; dpr: number; glRenderer: string; headless: boolean };
  frames: { variant: Variant; dpr: 1 | 2; phase: 'pan' | 'zoom'; meanFps: number; p95FrameMs: number; drawMsMean: number }[];
  open20kMs: number;            // JSON.parse of a 20,000-element string → store → rbush.load → end of first painted frame
  firstInkP95Ms: number;        // 20 synthetic pointerdowns: performance.now() at the end of the painting rAF minus event.timeStamp, 5,000-element scene present
  rbush: { load20kMs: number; queryP95Ms: number; moveAvgMs: number };   // moveAvgMs = remove + insert of one element
  freehand: { points: 500 | 1000 | 5000; getStrokeMs: number }[];
};
```

- [ ] **Step 1: Scaffold.** Root `package.json` (`private`, `packageManager`), `pnpm-workspace.yaml` (`packages: ["spikes/*"]`), the `s1-canvas` package with a `dev` script (`vite web`); add `spikes/*/out/` to `.gitignore`. Run `pnpm install`. Expected: `pnpm-lock.yaml` exists, no `package-lock.json`.
- [ ] **Step 2: `scene.ts`** `makeScene(n: number, seed: number, world: Rect): El[]`. Fixed mix per 5,000: 1,800 shapes (25% rotated), 500 lines/arrows, 1,500 text (60% Latin, 40% Arabic, 12–32 px), 400 math and 300 images (pre-rasterised offscreen bitmaps, 8 and 3 distinct), 500 freehand (40–200 points through `perfect-freehand`). `console.assert` the per-type counts for `n` = 5,000 and 20,000.
- [ ] **Step 3: `render.ts`** `renderScene(ctx: CanvasRenderingContext2D, els: El[], cam: Camera, variant: Variant): number`, returning the number of elements drawn. `direct` calls `fillText` every frame; `cached` draws text, math and images from bitmaps keyed `(id, v, zoomBucket)` (power-of-two buckets) and shapes and strokes from cached `Path2D`. Culling by `rbush`. Two canvases (scene, overlay), dirty-flag `requestAnimationFrame` loop. The worker variant is Step 6.
- [ ] **Step 4: `bench.ts`** (`?auto=1&variant=&dpr=`). Scripted camera: pan 5 s on a Lissajous path, then zoom 5 s oscillating 0.6 ↔ 1.4 about the centre, with the 5,000 elements packed into a 1000×600 world rect so all stay visible. Record rAF deltas and time spent in `renderScene`. At zoom 0.05 and 20 assert `renderScene`'s return equals the `rbush` viewport query count. Then `open20kMs`, `firstInkP95Ms`, the `rbush` timings and `getStroke` at 500 / 1,000 / 5,000 points. Print PASS/FAIL per threshold below and set `window.__s1`.
- [ ] **Step 5: Run** `pnpm --filter s1-canvas dev`, open `http://localhost:5173/?auto=1` for each of `variant=direct|cached` × `dpr=1|2` in a **foreground, headed** Chrome with devtools closed (background tabs throttle rAF). Read `window.__s1` with chrome-devtools MCP `evaluate_script`, or copy it from the on-page panel. Expected for the best variant at DPR 2 **[my call: thresholds]**: `meanFps ≥ 58` and `p95FrameMs ≤ 17.5` for pan and zoom; `open20kMs < 2000`; `firstInkP95Ms ≤ 16`; `rbush.load20kMs ≤ 50`, `queryP95Ms ≤ 1`, `moveAvgMs ≤ 0.1` (else build the R-tree in-house); `getStrokeMs ≤ 2` at 1,000 points (else in-house freehand); the zoom-extreme assertion holds.
- [ ] **Step 6: Only if every non-worker variant fails `frames` at DPR 2:** add `variant: 'worker'` (scene canvas on `OffscreenCanvas` in a worker) and re-measure. If that also fails, record the shortfall and name WebGL as the next rung (not built in M0).
- [ ] **Step 7: Write `RESULT.md`** (env, numbers, the four decision lines). Commit `spikes/s1-canvas`.

- [ ] **Step 2: `models.ts`** fetches `GET /api/v1/models` and checks each candidate supports `tools` and image input. Candidates: the `TUTOR_MODEL` default, the `TUTOR_FALLBACK_MODEL` default, and one model from another vendor. Print id and $/M in/out. If an id is gone, substitute and record it.

- [ ] **Step 5: Run** `pnpm --filter s3-openrouter exec tsx --env-file=../../.env run.ts --model <id> --test all` for each candidate, cheapest checks first (`streamingCost`, `toolLoop`, `dataCollection`, `imageInToolResult`, `arabic`, `cheap`) and the 3-turn `cache` check last, run only on the two leading candidates when the running total would otherwise pass the ceiling.
